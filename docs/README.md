## Нефункціональні вимоги (NFRs Matrix, резюме)

Повна матриця з виміряними значеннями та методами перевірки – табл. 1.3 у [1_analysis.md](./1_analysis.md).
Значення продуктивності задано для кластера з 3 вузлів на еталонному стенді (журнал на диску, команди до 256 байт).

| ID | Категорія | Вимога | Цільове значення |
| :--- | :--- | :--- | :--- |
| NFR-01 | Performance | Затримка запису команди, 1 клієнт | p50 ≤ 2 мс; p95 ≤ 10 мс |
| NFR-02 | Performance | Пропускна здатність запису, 16 клієнтів | ≥ 5 000 команд/с |
| NFR-03 | Performance | Лінеаризоване читання на лідері за дійсної оренди | p95 ≤ 1 мс |
| NFR-04 | Performance | Захоплення блокування без конкуренції | p99 ≤ 5 мс |
| NFR-05 | Scalability | Склад кластера | 3–5 вузлів, статичний склад, відмова (n − 1) / 2 вузлів |
| NFR-06 | Fault Tolerance | Новий лідер після аварійного завершення процесу лідера | ≤ 3 000 мс |
| NFR-07 | Reliability | Підтверджені команди під збоями вузлів і мережі | 0 втрачених, 0 повторно застосованих |
| NFR-10 | Security | Транспорт між вузлами | mTLS, рукостискання з HMAC-SHA256 |
| NFR-11 | Security | Десеріалізація (OWASP A08) | лише зареєстровані типи Kryo |
| NFR-13 | Infrastructure | Платформа | Java 21+, Spring Boot 3.2–3.5 і 4.x, без зовнішніх сервісів координації |
