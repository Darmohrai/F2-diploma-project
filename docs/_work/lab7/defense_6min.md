## Відповіді на ймовірні запитання

| Запитання | Відповідь |
| :--- | :--- |
| Чим Alternative Flow відрізняється від Exception Flow? | AF – мета досягається іншим шляхом (очікування, повтор, свіже значення з кешу); EF – мета недосяжна, система повертається в безпечний стан (відкат, компенсація, 503) |
| Чому include, а не extend, для фіксації в журналі? | без фіксації команда не існує – це обов'язкова частина кожного зміщення стану, тобто DRY-код |
| Як захищено від IDOR? | у керуванні немає ідентифікаторів об'єктів – лише перелічуване ім'я компонента; маркер узгодженості підписаний HMAC, підробка ігнорується |
| Чому лінтер не Vale? | Vale перевіряє стиль англійської прози; для україномовного тексту markdownlint дає перевірювану структуру (заголовки, таблиці, блоки коду), а стиль контролює нормоконтроль |
| Чому версія лінтера закріплена? | новий реліз з новими правилами не повинен робити зелений PR червоним без змін у документах |
| Що робить SpEL-ключ безпечним? | вираз задає розробник в анотації під час збирання; клієнт впливає лише на значення аргументу, яке стає рядком ключа |
