## Підказка для очікуваних «атак», які варто відхилити з аргументом

| Що може вимагати аудитор | Чому відхилено (коротко) |
| :--- | :--- |
| Argon2id / Bcrypt для паролів | у Kurin немає користувачів і паролів; вузол автентифікується сертифікатом + HMAC |
| JWT між вузлами | сторони – процеси одного застосунку з mTLS; JWT на тисячі `AppendEntries`/с не додає захисту |
| Kafka / Saga | порядок задає журнал Raft; розподілених транзакцій між сервісами фреймворк не виконує |
| Пагінація `/actuator/kurin` | колекції обмежені: 2–4 вузли, лише кількість блокувань, історія задачі ≤ 50 |
| Rate limiting у Kurin | на шлюзі (SRS-CON-07), у контракті – 429 + `Retry-After` |
